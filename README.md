# daily-commit

A small, private habit tracker and day planner with a built-in diary. Local-first and
offline: everything is stored on the device, and anything written in it is encrypted before it
is stored.

**Status:** in development (Beta 1: an Android app built from this repo and installed directly on
a phone; no store listing).

## Built with

React · TypeScript (strict) · Vite · Dexie (IndexedDB) · WebCrypto (AES-256-GCM) · Capacitor
(Android)

## Layout

```
src/        the app, one folder per feature, plus shared foundations:
            rules/ (pure calculations) · record/ (the only code that touches storage)
            vault/ (encryption) · ui/ (design tokens and components) · device/ (Android boundary)
tests/      mirrors src/, plus a test that enforces the dependency rules between folders
android/    the Android project (generated by Capacitor) and a small native plugin
public/     static assets copied into the app as-is
scripts/    repository tooling
```

## Develop

```
npm install
npm run check    # type-check + tests
npm run build    # production build into dist/
```

Requires Node 24 or newer. Tests run on Node's built-in test runner.
